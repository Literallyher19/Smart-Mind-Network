# Smart-Mind-Network
Design and Configuration of a multi-department enterprise network using Cisco Packet Tracer.

PROJECT OVERVIEW
This project involves the design and configuration of a simulated multi-department enterprise network for Smart-Minds
using Cisco Packet Tracer. It connects different departments namely; Finance, ICT, and Administration.

TECHNOLOGIES AND TOOLS USED
Cisco Packet Tracer
Cisco Routers and Switches
IPv4 Addressing and Subnetting
VLANs
DHCP and DNS
Access Control Lists(ACLs)
Secure Shell(SSH)
Spanning Tree Protocol(STP)

NETWORK IMPLEMENTATION
VLAN configuration-segmented the network into separate departmental broadcast domains
IP addressing and subnetting-assigned IP addresses and subnet masks to network devices
Inter-VLAN routing-enabled devices in different devices to communicate
DHCP-automatic IP address allocation
DNS-enables devices to get corresponding IP addresses to domain names.
SSH-enabled secure remote access of network devices.
STP-prevents layer 2 loop

NETWORK TESTING
Ping connectivity tests
IP configuration verification
DNS name resolution using nslookup

PROJECT OUTCOMES
Successfully designed and configured a simulated enterprise network demonstrating practical knowledge of networking infrastructure, routing, security and troubleshooting.

SKILLS DEMONSTRATED
Computer Networking

VLAN configuration
